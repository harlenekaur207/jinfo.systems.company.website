# Jinfo Systems LLC Website

Company website for Jinfo Systems LLC, featuring company information, AI projects, contact options, and meeting requests.

## View locally

Open `index.html` in a web browser.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select the `main` branch and `/ (root)` folder, then save.

## Notes

The current contact and meeting forms are visual only. Connect them to a form service, email service, or scheduling platform before using them for live customer requests.
